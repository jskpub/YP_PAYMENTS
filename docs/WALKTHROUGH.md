# 장바구니 기본 상태 지원금 미적용 변경 완료 보고서

요청해주신 내용에 맞춰 장바구니 기본 담김 상태가 **"지원금 미적용 상태"**로 시작하도록 변경 완료되었습니다.

---

## 🛠 반영 내역

1. **기본 담김 상태 `isSubsidyApplied: false` 설정**:
   - 장바구니에 담긴 3종 도서 (추천도서, 개인도서, 일반도서) 모두 초기 진입 시 **지원금 미적용 상태**로 시작됩니다.
   - 사용자/직원이 각 도서 카드의 **`[B2B 지원금 적용]` 버튼을 클릭할 때에만** B2B 회사 지원금이 계산되며 **지원금 적용완료** 상태로 전환됩니다.

2. **초기 화면 표시 금액**:
   - **추천도서 1권** (18,000원): 미적용 상태 (회사지원 0원 / 직원부담 18,000원) $\rightarrow$ 버튼 클릭 시 회사지원 18,000원 / 직원부담 0원으로 전환
   - **개인도서 1권** (20,000원): 미적용 상태 (회사지원 0원 / 직원부담 20,000원) $\rightarrow$ 버튼 클릭 시 회사지원 10,000원 / 직원부담 10,000원으로 전환
   - **일반도서 1권** (4,950원): 지원 대상 제외 (회사지원 0원 / 직원부담 4,950원 고정)
